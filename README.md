# LABCOL-2883 Webex Calling Customer Assist

Cisco Live Melbourne 2026 lab guide by Hussain Ali and Omer Ilyas.

[Read the lab guide online](https://joshua-tan-wai-kiat.github.io/labcol-2883-webex-calling-customer-assist-lab-guide/)

Ten lab tasks cover migrating Unity Connection auto attendants and Unified Communications Manager call queues to Webex Calling Customer Assist, assigning agents and supervisors, screen pops, and validation.

## Edit and publish

Edit the Markdown files in `docs/`, or use the pencil icon on the website. Commit to `main` to rebuild GitHub Pages automatically. Screenshots are in `docs/assets/images/`.

## Preview

```sh
python -m pip install -r requirements.txt
python -m mkdocs serve
```

Build with `python -m mkdocs build --strict`.

## Source conversion

The supplied Word guide provides the instructions, tables, screenshots, and author attribution. Word page numbers are replaced by section navigation. Legacy EMF screenshots were converted to PNG for browsers. All instructional screenshots are included, including screenshots containing sample passwords, at the owner’s explicit request. Sample credentials are for the disposable training sessions. The three original document branding assets are also retained under docs/assets/images/. The original Word file is not included.
