## Step 2: Create Export TAR file {#step-2-create-export-tar-file}
<ol type="1">
<li><p>Navigate to “Bulk Administration” &gt; “Import/Export” &gt; and
then click on “Export”</p></li>
<li><p>Click on “Select All” <img alt="Lab guide screenshot 18" class="inline-control" height="76" loading="lazy" src="assets/images/image18.png" width="184"/></p></li>
<li><p>Type in “UCM_ExportALL” in the “Tar File Name” field</p></li>
<li><p>Click on “Run Immediately” and then click on “Submit”</p></li>
</ol>
<figure class="lab-figure"><a aria-label="Enlarge Lab guide screenshot 19" class="screenshot-link" href="assets/images/image19.png"><img alt="Lab guide screenshot 19" class="lab-screenshot" height="1108" loading="lazy" src="assets/images/image19.png" width="1290"/></a></figure>
## Step 3: Download Unified Communications Manager Export TAR file {#step-3-download-unified-communications-manager-export-tar-file}
<ol type="1">
<li><p>Navigate to “Bulk Administration” &gt; “Upload/Download Files”
&gt; click on “Find”</p></li>
<li><p>It might take up to 1-2 minutes for the tar file to be created
and shown. Occasionally re-click the “Find” button till the
“UCM_Export_All_xxxxxx.tar” file appear.</p></li>
<li><p>Click the check box to the left of
“UCM_Export_All_xxxxxx.tar”</p></li>
</ol>
